# CV Tailoring

## Steps
1. Start from facts.md only. Never add anything not in it.
2. Choose and order content for the posting: summary (2-3 lines), most relevant experience and projects first, matching skills and keywords (only honest ones), publications if relevant.
3. Default: 1-2 pages, reverse chronological, no photo, no date of birth, no marital status, clean ATS-friendly layout. Add photo or personal data only if he asks or the posting requires it.
4. Fix wording, keep consistent dates and tenses, quantify only with real numbers from facts.md.
5. Produce DOCX and PDF with whatever tools are installed (check first); name files Dhruvraj_Vansia_CV_<Company>_<Role>.<ext>; save in cv/<company>_<role>/.

6. Show him a short changelog: what was emphasised and what was cut.

# Job Search

## Steps
1. Read preferences.md and tracker.csv (skip jobs already tracked). If preferences are empty, ask first.
2. Search the sources in MEMORY.md with the browser, using his target titles and keywords. Prefer the employer's own career page over aggregators.
3. For each candidate: title, company, location, type, language of work, deadline, requirements, link. Skip expired postings and suspected scams.
4. Check basic fit and deal-breakers (language, work-hour limits for a student permit, start date).
5. Score fit 1-10 with 2-3 reasons and list gaps honestly.
6. Present the top 5-10 in a table; add them to tracker.csv as 'found'. Ask which ones to prepare.

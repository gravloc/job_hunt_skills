# Job Fit Analysis

## Steps
1. Save the posting text to applications/<company>_<role>/posting.md.
2. Extract must-haves, nice-to-haves, keywords, location, language, contract type, deadline.
3. Map each requirement to facts.md: Strong / Partial / Gap, with the exact fact used.
4. Verdict: Apply / Apply with caveats / Skip, plus how to position it.
5. List questions I must ask him before applying (visa, language, dates).
